# CodeAlpha Java Development Internship - Month 1 Tasks

This repository contains the completed tasks for the **Java Development Internship (Month 1)** at **CodeAlpha**. All projects are written in Java and demonstrate fundamental Object-Oriented Programming (OOP) concepts, list handling, logic building, and basic console application structure.

---

## 📌 Projects Overview

### 1. Student Grade Tracker (`StudentGradeTracker.java`)
A Java console application that allows users to input grades for multiple students and generates a summary.
* **Features:**
  * Dynamic student count input.
  * Calculates average marks.
  * Finds the highest and lowest scores.
* **Concepts Used:** `ArrayList`, `Scanner`, loops, condition checking.

---

### 2. Simple Banking Application (`BankingApplication.java`)
A simple console-based banking system that simulates basic ATM features.
* **Features:**
  * Check account balance.
  * Deposit money.
  * Withdraw money with insufficient balance checking.
* **Concepts Used:** `Switch-case`, interactive menu loop, variable manipulation.

---

### 3. Hotel Reservation System (`HotelReservationSystem.java`)
A hotel room booking simulation system for standard and deluxe rooms.
* **Features:**
  * View room availability and booking status.
  * Book an available room.
  * Cancel existing bookings.
* **Concepts Used:** Object-Oriented Programming (`Room` class), `ArrayList` of objects, search and state updates.
